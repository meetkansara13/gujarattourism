# Gujarat Tourism - Django Project

A tourism booking and information web application built using Django.

## 🚀 Features
- User registration & login
- Tour packages listing
- Wishlist system
- Booking system
- Admin panel
- Support & Terms pages

## 🛠 Tech Stack
- Python
- Django
- SQLite 
- HTML, CSS, Bootstrap

## 📦 Installation

1. Clone repository:
   git clone https://github.com/meetkansara13/gujarattourism.git

2. Create virtual environment:
   python -m venv venv

3. Install requirements:
   pip install -r requirements.txt

4. Run server:
   python manage.py runserver
